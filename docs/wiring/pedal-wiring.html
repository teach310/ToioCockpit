ペダル圧力センサーの配線

CoreS3 の Port B（黒い Grove 端子）で感圧センサの電圧を読むための配線です。センサーの端子には FFC用コネクタを付けてピンヘッダ2本にしてあり、ジャンパワイヤでブレッドボードまでのばします。線の色は Grove ケーブルの色に合わせていますが、デュポン変換ケーブルによって色が違うことがあるので、端子の並びで確かめてください。

G8 に入れていいのは 3V 前後まで。 Port B の赤い線（5V）は使いません。感圧センサにじかにつなぐと、強く踏んだときに 5V 近くが G8 に入り、CoreS3 を傷めるおそれがあります。先をテープで絶縁しておきます。

ブレッドボードでの配線図 今の配線

実物の並びで描いた図です。ブレッドボードは、同じ番号の列の a〜e（と f〜j）が縦につながっています。色を付けた列がつながっているところです。

  1. 感圧センサのコネクタ（ピンヘッダ2本）に、ジャンパワイヤ（オス‐メス）のメス側を1本ずつ挿す
  2. ジャンパワイヤのオス側を a8 と a9 に挿す
  3. 10kΩ を b9 と b15 に挿す
  4. Port B の黄（G9）を d8、白（G8）を d9、黒（GND）を d15 へ
  5. Port B の赤（5V）は使わない。先をテープで絶縁する

ブレッドボードの上の並びは、センサーをじかに挿していたときと同じです。センサーのピンが挿さっていた a8・a9 に、ジャンパワイヤの先が来るだけです。センサーと抵抗には向きがないので、2本のジャンパワイヤはどちらがどちらの穴でもかまいません（図の青と緑は見分けるための色です）。抵抗の色は 10kΩ が 茶・黒・橙・金 です。

G9 はファームで HIGH にして約3.3Vを出します。センサーに流れるのは 0.3mA 以下なので GPIO で足ります。

使うセンサーとコネクタ

感圧センサ（四角形）MF02A-N-221-A01（Taiwan Alpha）。押すと抵抗が下がるシートです。端子に 2.54mmピッチFFC用コネクタ（2線用・ピンヘッダ変換）をかしめて、2.54mm 間隔のピンヘッダ2本にしてあります。ここにメスのジャンパワイヤを挿せば、センサーをブレッドボードから離して置けます。

抵抗は仕様書のグラフ（直径10mmのゴムで押したとき）から読んだ目安です。

このセンサーが測れるのは 1kg まで。 足で踏むと数 kg かかるので、すぐに値が頭打ちになり、センサーにも負担がかかります（寿命は 1kg で 1000 万回の試験値）。ペダルにするときは、スポンジやゴムを挟んで力を逃がします。シートの付け根から 5mm 以内は曲げず、配線部分も 90° 以上折らないでください。線をのばしたぶん、踏んだときにコネクタやジャンパワイヤが引っぱられないよう、線をテープなどで止めておきます。

回路

G9 から出した約3.3Vを、感圧センサと 10kΩ で分けて G8 で読みます。出力は 0〜3.3V に収まります。10kΩ は、このセンサーの 30g〜1kg の範囲を 0.5〜3V に広げられる値です。

G8 = 3.3V × 10k ÷ (10k + Rセンサ)

Port A（赤い端子）は I2C 用で、基板の中で 3.3V に引き上げられているので、センサーには使いません。

つないだら

  1. CoreS3 を USB でつなぐ
  2. pio run -e pedal -t upload で書き込む
  3. 画面の % とバー、電圧を見る（pio device monitor -e pedal でも見られる）
  4. 踏んでいないときに 0% になり、踏むと上がるかを確かめる。最大が 3000mV を大きく超えていないかも見る
  5. 線をゆらして値が飛ばないかを見る。飛ぶときはコネクタのかしめとジャンパワイヤの挿さり具合を確かめる
前に試した配線（ATOM Lite）

ATOM Lite の G32 で読んでいたときの配線です。A と B は最初のテスト、C は単四電池3本で動かしたときのものです。センサーはコネクタを付ける前で、ブレッドボードにじかに挿していました。

ATOM Lite でのブレッドボードの配線図

実物の並びで描いた図です。ブレッドボードは、同じ番号の列の a〜e（と f〜j）が縦につながっています。色を付けた列がつながっているところです。

C. 単四電池3本で動かし、G26 からセンサーに給電する

  1. 感圧センサのピンを a8（Pin1）と a9（Pin2）に挿す
  2. 10kΩ を b9 と b15 に挿す
  3. Grove の黄（G26）を d8、白（G32）を d9、黒（GND）を d15 へ
  4. Grove の赤（5V）は使わない。電池の＋とつながるので、先を必ず絶縁する
  5. 電池ボックスの黒いリード線を右のピン列の GND、最後に赤を 5V へ挿す。赤を挿すと電源が入る

G26 はファームで HIGH にして約3.3Vを出します。センサーに流れるのは 0.3mA 以下なので GPIO で足ります。G32 にかかるのも3.3Vまでで、値の出方は A と同じです。

電池をつないだまま USB をつながない。 USB の 5V が電池に流れ込み、アルカリ電池の液漏れや発熱の原因になります。書き込むときは、電池の赤い線を 5V ピンから抜いてから USB をつなぎます。使い終わったときも赤い線を抜きます（つないだままだと電池が減り続けます）。電池が減って約4.3Vを下回ると、ATOM Lite が動かなくなることがあります。

A. 3.3V から電源をとる

  1. 感圧センサのピンを a5（Pin1）と a6（Pin2）に挿す
  2. 10kΩ を b6 と b12 に挿す
  3. ATOM Lite の左のピン列の一番上（3V3）から、ジャンパワイヤで c5 へ
  4. Grove の白（G32）を d6、黒（GND）を d12 へ
  5. Grove の赤（5V）と黄（G26）は使わない。赤はほかとぶつからないよう、先をテープで絶縁する

B. Grove だけでつなぐ

  1. 感圧センサのピンを a8（Pin1）と a9（Pin2）に挿す
  2. 6.8kΩ を b2 と b8、10kΩ を c9 と c15 に挿す
  3. Grove の赤（5V）を d2、白（G32）を d9、黒（GND）を d15 へ
  4. Grove の黄（G26）は使わない。先をテープで絶縁する

抵抗の色は 10kΩ が 茶・黒・橙・金、6.8kΩ が 青・灰・赤・金 です。抵抗とセンサには向きがないので、どちら向きに挿してもかまいません。

A. 3.3V から電源をとる テスト用

電源だけ左のピン列の一番上の 3V3 からデュポン線でとり、信号と GND は Grove のままです。出力は 0〜3.3V に収まるので、センサーの範囲を全部使えます。

G32 = 3.3V × 10k ÷ (10k + RFSR)

B. Grove だけでつなぐ 配線が少ない

Grove の4本だけで済みます。感圧抵抗が 0Ω になるほど強く踏んでも、G32 は約 3.0V までに収まります。そのぶん読める範囲は A より少し狭くなります。

G32 の最大 = 5V × 10k ÷ (6.8k + 10k) ≒ 3.0V
